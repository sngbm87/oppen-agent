# Product Requirements Document (PRD) - Oppen Agent

**Version**: 0.1.0
**Status**: Draft - Stage 0
**Date**: 2026-05-28

## 1. Executive Summary
Oppen Agent is the ultimate AI coding agent: a persistent, self-evolving, swarm-capable super-agent optimized for AI Models. It combines the best public patterns from the entire AI agent landscape into one FAANG-tier, bug-free system.

## 2. Goals & Success Metrics
- Best-in-universe coding capability (long-horizon, multi-file, self-correcting)
- Full autonomy (daemon + heartbeat + cron + autopilot)
- AI Model optimization (routing, context, cost, safety)
- Zero bugs, 100% test coverage on critical paths, FAANG quality
- Incorporates all 25 wishes and addresses all gaps from history
- Quantum orders-of-magnitude expansion ready

## 3. Scope
In: Core daemon, cognitive brain, quantum layer, tool harness, coding bypass, swarm, verification, polyglot, self-evolution, benchmarks.
Out (v1): Full GUI, mobile apps, enterprise multi-tenancy.

## 4. Functional Requirements
- Persistent background daemon with configurable heartbeat and cron
- YOLO Cosmic Eternal Memory with geometric + λ-Memory
- Dynamic AI Model routing with fallback and cost tracking
- Full tool calling with validation, sandbox, parallel, observability
- Coding bypass mode with Claude Code/Codex style long-horizon loops
- Swarm coordination with stigmergy and task DAGs
- Witness verification + HoTT types for safety
- Self-growth (Cambium-style) and meta-harness
- Full polyglot FFI (Go/Rust/Python/TS/Eshkol/etc.)
- OAuth for all major services
- Cross-platform (Windows, Linux, macOS)

## 5. Non-Functional Requirements
- Performance: Sub-second tool calls, efficient token usage
- Reliability: 99.9% uptime for daemon, graceful degradation
- Security: OAuth, sandbox, PII redaction, audit logs
- Quality: TDD, lint 0 issues, ADRs, full docs
- Scalability: Horizontal for swarm, vertical for heavy models

## 6. User Stories
- As a solo dev, I want to give high-level coding goals and have the agent autonomously plan, code, test, PR without constant prompting.
- As a researcher, I want the agent to use the best model for the task and explain its reasoning.
- As a builder, I want to extend the agent with new tools/models/skills easily.

## 7. Acceptance Criteria
- All 25 wish-list items satisfied
- All identified harness gaps for AI Models closed
- Passes the 25 missing frontier benchmarks at high level
- FAANG-tier repo quality (all required files, ADRs, tests, CI)
- Zero critical bugs in core loops

## 9. Risks & Mitigations
- Complexity: Modular harness design, TDD, incremental delivery
- Model costs: Cost governance harness, local model preference
- Safety: Multi-layer verification + guardrails
